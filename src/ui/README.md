# src/ui — owned by Codex

Everything visual lives here. Codex builds it from UI tickets (`docs/ui/tickets/`). Claude connects it to routes and data.

```
src/ui/
  theme/        globals.css (tokens, base styles), fonts.ts
  primitives/   shadcn/ui components (generated by `npx shadcn add`; edit sparingly)
  components/   shared building blocks (Money, PriceBreakdown, StatusBadge, ActionBar, …)
  shells/       page shells (PublicShell, AppShell, DetailPageShell, AdminShell)
  screens/      whole screens, one folder per area (e.g. screens/bookings/BookingHubScreen.tsx)
  previews/     *.preview.tsx files + registry.ts (shown at /dev/ui, screenshotted by npm run test:ui)
  lib/          UI-only helpers (cn, hooks)
```

Rules (full list in `AGENTS.md`):
- UI code imports only from `@/ui`, `@/contracts`, `@/shared`, and UI libraries. Previews and tests may also import `@/fixtures`.
- Components are **synchronous and isomorphic**: no `async` components, no data fetching, no `next/headers`, no server actions defined here.
- Data arrives as typed props (from `@/contracts`). Mutations arrive as handler props (`ActionHandler`), which resolve to `ActionResult`.
- Every component or screen gets a preview, registered in `previews/registry.ts`.
