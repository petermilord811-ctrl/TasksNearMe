# UI-036 handoff: landing page v2 (motion, canvas, map, new brand)

Built by **Claude**, not Codex: Codex reached its usage limit at the start of the run, and the owner chose to have Claude build the ticket to the same bar (recorded in `docs/automation/decisions.md`).

## 1. Built

**Brand and theme**
- `src/ui/theme/globals.css`: the new palette, light and dark (token values are in `docs/ui/design-system.md` §2.1). It adds the iridescent light (`--iri-1…4`, `--iridescent`), category colors (`--cat-*`), glass (`--glass*`), map colors (`--map-*`), motion variables (`--dur-*`, `--ease-*`), keyframes (mask rise, enter, bloom, drift, pulse ring, sheen, draw), the `text-iridescent`, `glass` and `map-fade` utilities, and scroll reveals (`html[data-motion="on"] [data-reveal]`).
- `src/ui/theme/fonts.ts`: Bricolage Grotesque (display and headings), Instrument Serif italic (the one vivid word), DM Sans (body).
- `src/ui/theme/theme-script.ts`: applies the saved theme (`tnm-theme`) and the motion flag before paint.
- `src/ui/shells/logo.tsx` (`BrandMark`, `Wordmark`, `Logo`) and `public/ui/brand/{mark,icon,logo}.svg`. **The logo idea:** a map pin holding a check (a task done nearby) with a soft ripple, on a tile of iridescent light. In the lowercase wordmark, "near" carries the color.
- `src/ui/shells/top-bar.tsx` (a glass pill that condenses on scroll, hides going down and returns going up, but never while focused or under reduced motion), `theme-toggle.tsx` (light/dark switch), `public-shell.tsx` (`variant: 'landing'`), `public-account-links.tsx`.

**Motion system** (`src/ui/motion/`)
- `tokens.ts`: durations 120/200/320/560/800 ms, `out` and `inOut` easings, `bloom` and `follow` springs, a 70 ms stagger.
- `motion-root.tsx`: switches scroll reveals on after hydration, and never under reduced motion.
- Primitives: `reveal.tsx` (rise or bloom, attribute-only so it works in server components), `mask-text.tsx` (headline lines through a mask, CSS only), `magnetic.tsx`, `spotlight.tsx`, and `count-up.tsx` (display only; it lands on the exact `formatMoney` value, and screen readers get the final value).

**Landing** (`src/ui/landing/`)
- `landing-state.tsx`: one shared state, so the parts respond to each other. It holds the active category, the highlighted task, the visitor's location (asked for only on a button press, and it never leaves the browser), and the pointer.
- `hero.tsx`: mask-revealed headline, magnetic primary call to action, `ask-pill.tsx` (cycles real examples, then morphs into a category panel), `floating-cards.tsx` (real tasks and helpers at different depths, with parallax and tilt; wide screens only).
- `canvas/engine.ts` + `canvas/hero-canvas.tsx`: **"Neighborhood light"**.
  - Category-colored task points and ringed helper points drift through soft iridescent light. A helper near a task links to it, and both glow.
  - The cursor brightens and attracts points. A focused category glows while the rest go quiet.
  - **It avoids the text:** the hero's text boxes are clear zones, and points fade to a whisper over them.
  - Phones get fewer points (density by area). It pauses off screen and in background tabs, and has a pause control.
- `map/`:
  - `task-map.tsx`: a static SVG map first, then MapLibre once near the viewport; it falls back to static on any failure.
  - `maplibre-view.tsx`: cooperative gestures, clusters, area circles in meters, a feature-state highlight, and a theme repaint.
  - `static-map.tsx`: real river and road lines, area circles.
  - `restyle.ts`: recolors any OpenMapTiles style with the `--map-*` tokens.
  - `pin-card.tsx`: a glass card that blooms from its pin.
  - `nearby-list.tsx`: the accessible list; hover and focus light the pin.
  - `map-math.ts`: distance sort, service area, projection.
- `map-section.tsx` (filter chips, "Use my location", the outside-area waitlist), `category-cards.tsx`, and `sections.tsx` (categories, steps with a drawn path, pricing, trust, helpers with the founding reward, coverage, FAQ, closing band).
- `src/ui/screens/public/home-screen.tsx`: composes the page.

## 4. Dependencies added
- `motion` 14.12.0: springs, layout morphs (the ask pill) and `LazyMotion` with `domAnimation`, so it stays small.
- `maplibre-gl` 6.18.0: the interactive map. It loads on demand and isn't in the first-load bundle. Its worker is served from `/vendor/maplibre-gl-worker.mjs` (a route handler).
- Tiles come from OpenFreeMap (free, no key), set by `MAP_STYLE_URL` / `MAP_ATTRIBUTION`.
