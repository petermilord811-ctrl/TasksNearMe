# UI-045 handoff: the profile photo on helper pages

Built by **Claude** while Codex is out (owner request: "update all profile pages": the helper profile editor and the public helper profile).

1. **Built:**
   - Helper profile editor: the Profile section starts with `ProfilePhotoField` (the same photo as the account page; it says where the photo shows), then the profile form.
   - Public helper profile (`helper-profile-screen.tsx`): a new header: a soft brand band with the photo (or initials) across its lower edge, the name and headline beside it on wider screens, area, remote and founding badges in one row, verification badges; on the right, the rating, two stat tiles (tasks completed, response time), member since, and a full-width "Request …" button that wraps for long names.
   - Helper cards, offer cards and the offer comparison pass the helper's `photo` to `InitialsAvatar` (every `HelperSummary` carries it when the helper added one).
   - Previews: `screen-helper-profile/sam-photo`, `screen-helper-profile-editor/with-photo`.
2. **Contracts used:** `HelperProfileEditorData.person` (display name, initials, photo), `HelperProfileEditorHandlers.onUploadPhoto` / `onRemovePhoto`, `PersonSummary.photo`.
3. **Message namespaces:** `forms.profilePhoto.notes.helperEditor`, `helperProfile.preview.samPhoto`, `helperProfileEditor.screen.previews.withPhoto`.
4. **Dependencies added:** none.
5. **Contract requests:** none.
6. **Known gaps or follow-ups:** invite cards, bookings, messages and reviews still show initials for the other person; where their view holds a helper summary, passing `photo` is a one-line change each.
7. **Previews to review first:** `screen-helper-profile/sam-photo` (phone, then desktop).
