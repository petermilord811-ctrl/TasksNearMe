# UI-041 handoff: landing page interactions

Built by **Claude** on `main` (the owner asked for smoother motion where "elements collaborate when I click").

1. **Built:**
   - `src/ui/landing/landing-state.tsx`: a click *selects* (`selectedCategory`, `focusTask`), pointing only *previews* (`previewCategory`); `activeCategory` and `litTaskId` are what the page shows. Fixes hovering a category card or the hero's menu clearing the map's filter.
   - `map-section.tsx`: the filter pill slides between chips (shared layout), the count line rolls and is announced, the location button resizes smoothly.
   - `map/nearby-list.tsx`: rows glide to new places, leave and arrive in order; leaving rows are inert and hidden from assistive tech; the picked task is outlined.
   - `map/maplibre-view.tsx`: a pick flies the map to that category (back out when cleared); pins fade instead of jumping; effects only touch the map instance that finished loading (no more "Style is not done loading"); the pin card opens below pins near the top edge and stays inside the map.
   - `floating-cards.tsx`: a task card shows its task on the map (the page glides down, the pin opens, the row lights); a modified click still opens the task; the lean-to-cursor loop pauses off screen.
   - `fee-explorer.tsx`: price chips; every amount runs to its new value; a bar splits what the helper earns from the fees.
   - `src/ui/shells/theme-toggle.tsx`: the new theme spreads as a circle from the switch (View Transition).
   - `category-cards.tsx` and `category-screen.tsx`: the card's icon carries into the category page's header (React `<ViewTransition>`).
   - `src/ui/motion/count-up.tsx`: `TweenMoney`.
   - Global: smooth in-page scrolling (`data-scroll-behavior="smooth"`); every View Transition is off under reduced motion.
