# UI-048 handoff: "Write it for me" for helpers

Built by **Claude** while Codex is out (owner request: "I added an Anthropic API key, make it useful with features"). Posting's "Help me describe this" already had its UI; it now runs on Claude with no UI change.

1. **Built:**
   - `src/ui/components/forms/ai-draft.tsx`: `AiDraftButton` (a spark, then a spinner and "Writing…") and `AiDraftStatus` (drafted with Undo, undone, or why it failed, in a live region).
   - `src/ui/screens/helper/helper-forms.tsx`: `HelperProfileForm` takes `onDraft`; a "Write it for me" group above the fields (a few words about you, "Draft my profile", then "Draft again"). The draft fills the headline and about-me; Undo puts back what was there; nothing saves until Save.
   - `src/ui/screens/work/offer-fields.tsx`: `OfferFields` takes `onDraftMessage`; under the message, "Write it for me" sends the start time, what they'll bring, and what's typed so far as notes. The draft replaces the message; Undo restores it.
   - Previews: `screen-helper-onboarding/profile-drafted`, `screen-helper-task/offer-drafted` (`click-on-load.tsx` presses the button on load). The existing profile, editor and offer-form previews now show the controls.
   - Tests: `profile-draft.test.tsx` (5), `offer-draft.test.tsx` (3).
2. **Contracts used:** `profileDraftInputSchema`, `ProfileDraftInput`, `ProfileDraftResult`, `HelperOnboardingHandlers.onDraftProfile`, `HelperProfileEditorHandlers.onDraftProfile`, `HelperOnboardingPageData.aiDraftingEnabled`, `HelperProfileEditorData.aiDraftingEnabled`, `OfferMessageDraftInput`, `OfferMessageDraftResult`, `HelperWorkHandlers.onDraftOfferMessage`, `HelperTaskView.aiDraftingEnabled`.
3. **Message namespaces:** `forms.aiDraft`, `helperOnboarding.forms.profile.ai`, `helperTask.form.aiDraft` / `aiDraftHint`, preview titles.
4. **Dependencies added:** `@anthropic-ai/sdk` 1.3.0 (server only; the UI never imports it).
5. **Contract requests:** none.
6. **Known gaps or follow-ups:** the controls show only when the market's `ai_drafting` flag is on and writing help is set up; Codex may want to review the wording and the dashed panel against the brand.
7. **Previews to review first:** `screen-helper-onboarding/profile-drafted` (phone first), `screen-helper-task/offer-drafted`.
