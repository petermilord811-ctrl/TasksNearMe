# UI-044 handoff: the account page's photo and contact details, and six-box codes

Built by **Claude** while Codex is out (owner request: "complete authentication, 6-digit code principle, and update all profile pages").

1. **Built:**
   - `src/ui/components/forms/code-input.tsx`: `CodeInput` (six boxes drawn over one real input: `autocomplete="one-time-code"`, numeric keyboard, paste and the phone's code suggestion work; letters and spaces are dropped; the sixth digit calls `onComplete` once per code) and `CodeFormField` (react-hook-form: label, hint, error). The sign-in code step uses it and submits on the sixth digit.
   - `src/ui/components/forms/profile-photo-field.tsx` (`ProfilePhotoField`): the avatar as people see it, "Add a photo" / "Change photo" (the file input stays focusable), "Remove photo", the size check before uploading, and the result in a live region. A saved photo shows at once; the refreshed page data replaces it.
   - `src/ui/screens/account/account-contact.tsx` (`AccountContact`): contact details (email, phone) with "Change" / "Add", each opening a dialog: the new address or number, then the code. "Send a new code" and "Use a different email/number" on the code step; an address taken after the code was sent goes back to the first step with the error. Each opening starts over.
   - `account-screen.tsx`: the profile card (photo, then name) and the new contact details card. `InitialsAvatar` takes an optional `photo` and an `xl` size; the account menu shows the photo.
   - Previews: `screen-account/{photo-uploading,photo-error,email-change,email-in-use,phone-add,phone-code-wrong}` (plus the existing ones, now with the photo and contact card); `account-examples.tsx` replays choosing a file and typing an address or a code.
   - Tests: `code-input.test.tsx` (6), `account-screen.test.tsx` (11 new: photo upload, size limit, server refusal, removal; email change, taken address, wrong code and resend, taken after the code; phone add, rate limit, starting over), sign-in tests updated for auto-submit.
2. **Contracts used:** `AccountPageData.profile.initials` / `photo`, `AccountPageData.maxPhotoMegabytes`, `AccountHandlers.onUploadPhoto` / `onRemovePhoto` / `onStartEmailChange` / `onConfirmEmailChange` / `onStartPhoneChange` / `onConfirmPhoneChange`, `emailChangeConfirmInputSchema`, `CONTACT_CODE_MINUTES`, `ShellViewer.photo`, field error code `unchanged`.
3. **Message namespaces:** `account.contact`, `forms.profilePhoto`, `forms.fields.email.in_use` / `unchanged`, `forms.fields.phone.unchanged`, `forms.fieldErrors.unchanged`, `verification.photo`; `account.profile` lost its read-only email and phone lines.
4. **Dependencies added:** none.
5. **Contract requests:** none.
6. **Known gaps or follow-ups:**
   - The preview harness runs axe inside each preview's root only; dialogs render in a portal outside it. These previews were also checked with full-page axe at 360 and 1280 (no serious issues). Worth extending the harness to include open dialogs, then fixing whatever it finds in older previews.
   - The resend button has no countdown here (the server's limits answer with "try again after …"), unlike sign-in.
7. **Previews to review first:** `screen-account/email-change` and `screen-account/phone-code-wrong` (phone first), then `screen-account/helper`.
