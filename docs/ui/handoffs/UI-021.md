# UI-021 handoff: quality pass

Built by **Claude** on `main` (Codex is at its usage limit).

1. **Known issues, each fixed:**
   - **Native file inputs** (posting photos, support photos, and also completion, problem reports, messages and work samples): one shared control, `src/ui/components/forms/file-chooser.tsx` (`FileChooser`). The real input stays in the page, visually hidden but focusable; a labelled button opens it (its focus ring shows when the input has focus); wide screens get a drop zone. The input's accessible name comes from the field label (`aria-labelledby`), so labels aren't read twice. Progress, errors and removals keep their existing announcements. A form that reads the file on submit (work samples) keeps the choice and shows its name (`keepSelection`).
   - **The thread's date chip:** day separators no longer stick, so they never cover a photo while scrolling.
   - **LCP warnings:** a sweep of every preview group found three images: the problem report's lead photo (`CompletionSummary leadsPage`), and the work sample gallery and completion summary previews (`eagerFirst`, `leadsPage`). Those load eagerly; everything else stays lazy. No preview logs the warning now.
   - **The allowance test:** `booking-hub-screen.test.tsx` checks the allowance on `deskBookingPosterCompletionWithExpenses` (a charge that funds it, $86.00), and the stray $20 allowance is gone from `movingBookingPosterConfirmed`.
2. **Keyboard, screen reader and phones** (a sweep of all 845 previews at 320 px: overflow, developer words, touch targets, heading outline):
   - No horizontal scrolling on any preview at 320 px.

The rest of the flags were labelled rows already 44 px tall, stretched card links, hidden Radix form inputs, the skip link, or the primitives gallery.
   - Headings: every screen has one h1 and no skipped levels.
   - Dialogs return focus to their trigger (new strike reversal dialog included, with a test).
